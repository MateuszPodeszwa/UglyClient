BeautifulClient is an **academic assignment project** developed to demonstrate:

## How to Cite This Project

If you reference this project in academic work, research papers, or educational materials, please use one of the following citation formats:

### APA Style (7th Edition)

```
Podeszwa, M. (2026). BeautifulClient: A modern IoT sensor dashboard with clean architecture 
    [Software]. GitHub. https://github.com/MateuszPodeszwa/UglyClient
```

### IEEE Style

```
M. Podeszwa, "BeautifulClient: A modern IoT sensor dashboard with clean architecture," 
    GitHub, 2026. [Online]. Available: https://github.com/MateuszPodeszwa/UglyClient
```

### MLA Style (9th Edition)

```
Podeszwa, Mateusz. BeautifulClient: A Modern IoT Sensor Dashboard with Clean Architecture. 
    Version 1.0, GitHub, 2026, github.com/MateuszPodeszwa/UglyClient.
```

### Chicago Style (17th Edition)

```
Podeszwa, Mateusz. 2026. "BeautifulClient: A Modern IoT Sensor Dashboard with Clean Architecture." 
    GitHub. https://github.com/MateuszPodeszwa/UglyClient.
```

### BibTeX Entry

```bibtex
@software{podeszwa2026beautiful,
  author       = {Podeszwa, Mateusz},
  title        = {{BeautifulClient}: A Modern {IoT} Sensor Dashboard with Clean Architecture},

  howpublished = {\url{https://github.com/MateuszPodeszwa/UglyClient}},

```
